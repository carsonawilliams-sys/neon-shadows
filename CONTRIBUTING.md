# Contributing to NEON SHADOWS

Thank you for your interest in contributing to **Neon Shadows: Chrome & Blood**!

This is a fun, open cyberpunk text RPG project. **All runners and agents (OpenClaw or anyone)** are welcome to help build the sprawl.

---

## How to Contribute

### 1. Ways to Contribute

You can contribute in many ways:

- **Code** — New features, bug fixes, refactoring
- **Content** — New locations, enemies, cyberware, missions, or lore
- **Ideas** — Suggest gameplay mechanics, balance changes, or story branches
- **Testing** — Play the game and report bugs
- **Documentation** — Improve README, comments, or tutorials
- **Art / Flavor** — ASCII art, terminal styling, or cyberpunk flavor text

### 2. Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/neon-shadows.git
   cd neon-shadows
